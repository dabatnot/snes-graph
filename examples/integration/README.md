# Trois consommateurs ca65 / Three ca65 consumers

Depuis la racine / From the repository root:

```sh
npm ci
npm run examples:integration
```

Installer au préalable ca65 et ld65 (cc65), accessibles dans PATH.
Requires ca65 and ld65 (cc65) on PATH. Works with Node under Linux and Windows;
the generated ROMs are platform independent.

| Dossier / Directory | Comportement / Behavior |
|---|---|
| background | Décor de cristaux / Crystal background |
| animated-sprite | Deux poses alternées toutes les 16 images / Two poses, 16 frames each |
| palette-swap | B bascule Azure/Amber une fois par pression / B toggles Azure/Amber once per press |

Les sorties sont dans `artifacts/integration/<nom>/`: projet `.snesgraph`, exports
standards dans `export/`, instantanés VRAM/CGRAM/OAM, sources copiées et `example.sfc`.
Ouvrir la ROM dans Mesen. Les graphismes sont originaux et générés par le script.
Ces exemples utilisent le compilateur de scènes de l’application. Le runtime
est volontairement limité à ces scènes : il charge la VRAM à l’initialisation,
puis CGRAM/OAM en VBlank. Ce n’est pas un moteur de jeu général.

Outputs are under `artifacts/integration/<name>/`: editable project, ordinary
exports in `export/`, VRAM/CGRAM/OAM snapshots, copied sources and `example.sfc`.
Open the ROM in Mesen. Original graphics are generated by the script. The examples
use the application's scene compiler. This small runtime loads VRAM at startup
and CGRAM/OAM during VBlank; it is specific to these scenes, not a general engine.

## Vérification / Verification

Mesen 2 CLI (Linux shell example):

```sh
SNES_GRAPH_TEST_OUTPUT="$PWD/artifacts/integration/palette-swap" Mesen \
  --testrunner --timeout=15 --enableStdout \
  --debug.scriptWindow.allowIoOsAccess=true \
  artifacts/integration/palette-swap/example.sfc scripts/verify-integration.lua
```

Le script sauvegarde les images 10, 26, 40 et 60 et presse B sur deux intervalles.
Pour palette-swap : 26 et 40 sont identiques (bouton maintenu puis relâché),
60 retrouve 10 après la deuxième pression. Pour animated-sprite : 10 et 26
montrent deux positions différentes. Ne pas confondre cette validation dans
l’émulateur avec une validation sur console.

The script captures frames 10, 26, 40 and 60 and holds B twice. For palette-swap,
26 and 40 match, and 60 returns to 10 after the second press. For animated-sprite,
10 and 26 show different positions. Emulator evidence is not console validation.
