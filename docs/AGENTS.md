# Documentation

(French) and `guide/en.html` (English), with identical anchors and a language selector.
Keep existing URLs. English is the primary entry point. Use the repository-local
[documentation skill](../.agents/skills/snes-graph-docs/SKILL.md).
Keep capture recipes in `guide/README.md`. Capture the actual interface in each
edition's language; never manufacture screenshots. Record web/native provenance.
Distinguish intended behavior, build checks, observed UI behavior and hardware proof.
Preserve the dates and limits of historical validation. Add no documentation framework.
